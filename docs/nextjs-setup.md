# Next.js Setup Notes

## Minimal runtime assumptions

- App Router under `app/src/app`
- TypeScript enabled
- Prisma as data layer
- Supabase or PostgreSQL for persistence

## Required dependencies

- `next`
- `react`
- `react-dom`
- `typescript`
- `@types/react`
- `@types/node`
- `prisma`
- `@prisma/client`

## Recommended additions later

- `zod`
- `clsx`
- `tailwindcss` if utility-first styling is desired
