# SHAMOOS Studio Notion Templates

## 1. 목적

이 문서는 SHAMOOS Studio에서 Notion을 운영할 때 바로 복제해서 사용할 수 있는 페이지 템플릿을 정의한다.

핵심 목표는 다음과 같다.

- 데이터베이스는 정형 속성으로 관리한다.
- 페이지 본문은 사람이 읽는 작업 맥락으로 채운다.
- 모든 핵심 페이지는 다음 행동을 바로 이어갈 수 있어야 한다.

## 2. 기본 템플릿 원칙

- 제목만 있는 페이지를 만들지 않는다.
- 각 페이지에는 요약, 상태, 다음 행동, 연결 항목을 둔다.
- Decision Log는 원인과 대안을 반드시 포함한다.
- Meeting 페이지는 회의록이 아니라 실행 출발점이어야 한다.

## 3. Home Template

### 용도

Studio 전체 운영 홈.

### 구조

```text
SHAMOOS Studio Home

1. Today
2. Active Products
3. Active Projects
4. Open Decisions
5. Upcoming Meetings
6. Open Tasks
7. Latest Documents
```

### 권장 블록

- 오늘의 우선순위
- 진행 중인 제품
- 긴급한 의사결정
- 이번 주 회의
- 빠른 이동 링크

## 12. AI Prompt Template

### 용도

프롬프트를 버전 관리하고 재사용하기 위한 템플릿.

### 페이지 섹션

```text

- Purpose
- Input variables
- Prompt body
- Output format
- Model config
- Version notes
```

### 운영 규칙

- 버전 번호를 항상 적는다.
- 입력 변수 예시를 남긴다.
- 출력 형식을 고정한다.

이 7개 템플릿만으로도 SHAMOOS Studio의 핵심 운영 흐름을 충분히 커버할 수 있다.
